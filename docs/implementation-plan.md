# План реализации Apex Building Group

Цель: сайт на трёх языках по docs/design.md. Реализация в текущей сессии; дизайн и запуск уже поручены пользователем.

- [ ] Подготовить предоставленный логотип, локальные шрифты и оптимизированные интерьерные фотографии. Зафиксировать источники и лицензии.
- [ ] Записать содержание в content/ru.mjs, content/es.mjs, content/en.mjs. Сохранить подробное содержание всех десяти этапов и контакты из материалов.
- [ ] Создать генератор scripts/build.mjs и шаблон src/template.mjs. Генерировать готовый HTML, языковые URL, метаданные, JSON-LD и sitemap относительно SITE_URL.
- [ ] Создать адаптивные стили src/styles.css, мобильное меню и реальную заявку через WhatsApp в src/main.js. Реальные проекты и команда должны добавляться через контентные файлы.
- [ ] Проверить браузером компьютер, телефон, три языка, SEO, этапы, форму, отсутствие JS, префикс пути. Исправить обнаруженные проблемы.
- [ ] Настроить Pages workflow, написать инструкцию редактирования и подключения домена. Опубликовать сайт при доступном GitHub и проверить публичный адрес.

Ограничения: не придумывать опыт, проекты, специалистов, адрес, цены или гарантии. Не покупать домен. Не отправлять тестовые сообщения компании. Исходные личные материалы не выкладывать в репозиторий.
