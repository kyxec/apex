# Apex Building Group — сайт компании

## Задача и исходные данные
Создать выразительный сайт компании по ремонту под ключ в Валенсии, который объясняет услуги и приводит обращения в WhatsApp, по телефону и email. Источники: информация.txt, комментарии.txt, предоставленные логотипы и цветовая палитра. Пользователь поручил самостоятельно изучить материалы и приступить к реализации. Подтверждены русский, испанский и английский языки.

## Визуальное решение
Архитектурная композиция с крупным интерьерным изображением и заголовком, свободными полями и спокойной геометрией. Присланный логотип, Manrope для заголовков и текста. Палитра: Stormy Teal #32707c, Oxidized Iron #a8371c, Pale Oak #d4c4b7, белый #ffffff, текст #23383a, светлый фон #f6f4f0. Бирюзовый раздел о компании и тёмный контактный раздел придают странице ритм; кирпичный выделяет основные действия.

## Структура
Главный экран → услуги → компания и организация ремонта → интерьерные направления → 10 раскрывающихся этапов → направления работы специалистов → FAQ → контактная форма → подвал. Никаких выдуманных отзывов, стажа, цифр, сотрудников или выполненных проектов. Стоковые фотографии явно отмечены как иллюстрации. Данные проектов и специалистов хранятся отдельно и принимают реальные фото, имена и описания.

## Технологии и SEO
Статическая генерация средствами Node.js без зависимостей для production. Готовый HTML по адресам / (русский), /es/, /en/. Уникальные метаданные и H1, самоканоникализация, взаимные hreflang, sitemap, robots.txt, JSON-LD Organization, WebSite и Service. Основной контент доступен без JS. Локальные шрифты и адаптивные WebP. Деплой GitHub Actions на Pages, URL берётся из окружения; домен можно сменить без изменения шаблонов.

## Заявка
Имя и телефон обязательны, описание необязательно. Браузерная валидация и понятное объяснение: кнопка открывает WhatsApp с подготовленным сообщением, пользователь отправляет его сам. После нажатия показывается ссылка продолжения и альтернативный email. Никакой имитации отправки или хранения заявки.

## Проверка
Сборка; проверка языков, ссылок, ассетов и SEO; браузерная проверка трёх языков, мобильного меню, всех этапов, формы и открываемого WhatsApp URL без отправки; скриншоты компьютера и телефона; проверка страницы без JS и размещения под префиксом GitHub Pages.
